# 1. Choosing your IDE:

First off, decide if you want to download JupyterLab or Jupyter Notebook.

Both of these will still be in your web browser (opened from your terminal), but they do different things:
Jupyter Notebook:
- Basic file browser that opens in a separate window
- Each new file opens a separate browser tab
- Does not natively have terminal access

JupyterLab:
- Multi-tab workspace
- Can open notebooks, terminal, text editor, and CSV views side-by-side.
- Can visualize open csv files


# 2. Check Installations

Before installing one of the two IDE's, make sure that pip and python are properly installed on your computer. 

You will need these to create the a new folder for the project and install the Jupyter IDE with other libraries to that project.

1. Check that python was properly installed:

**MacOS**
```sh
python3 --version
```

**Windows**
```sh
python --version
```

If python was never installed, install now:
**MacOS**
```sh
brew install python #click `y` if prompted
```

**Windows**
```sh
winget install -e --id Python.Python.3.12
```


2. Check that pip was properly installed:
**MacOS**
```sh
pip3 --version
```

**Windows**
```sh
pip --version
```

If pip was never installed (it should be installed with the python package), install now:
**MacOS**
```sh
python3 -m pip install --upgrade pip
```

**Windows**
```sh
python -m pip install --upgrade pip
```


# 3. Create a new directory/folder for the project

This is still done fully inside the terminal.

**MacOS**
```sh
ls
cd projects-folder
mkdir jupyter-project
cd jupyter-project
python -m venv .venv # create environment
source .venv/bin/activate # run your environment
```

**Windows Command Prompt**
```sh
ls
cd projects-folder
mkdir jupyter-project
cd jupyter-project
python -m venv .venv # create environment
.venv\Scripts\activate # run your environment
```

**Windows PowerShell**
```sh
ls
cd projects-folder
mkdir jupyter-project
cd jupyter-project
python -m venv .venv # create environment
.\.venv\Scripts\Activate.ps1 # run your environment
```



# 4. Install the correct IDE:

1. JupyterLab
**MacOS**
```sh
python -m pip install jupyterlab # can also install other libraries on this line like 'python3 -m pip install jupyterlab pandas numpy matplotlib'
jupyter lab # runs project
```

**Windows**
```sh
python -m pip install jupyterlab
jupyter lab # runs project
```


2. Jupyter Notebook
**MacOS**
```sh
python -m pip install notebook
jupyter notebook # runs project
```

**Windows**
```sh
python -m pip install notebook
jupyter notebook # runs project
```
